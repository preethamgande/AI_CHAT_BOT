# AI_CHAT_Application

A full-stack AI-powered chat application that allows users to register, log in, and interact with an AI assistant in real-time. The application supports chat history persistence using MongoDB Atlas and streaming AI responses

<img width="1880" height="855" alt="image" src="https://github.com/user-attachments/assets/aa16f030-4c5f-4cdc-9585-79588b8d36ca" />

## 🚀 Features

- 🔐 User Authentication (Register / Login / Logout)
- 💬 Real-time AI Chat (Streaming responses)
- 🧠 AI-powered responses using Mistral API
- 🗂 Chat history with sidebar navigation
- ☁️ MongoDB Atlas for cloud data storage
- 🌐 Full-stack deployment (Frontend + Backend)

## 🛠️ Technologies Used

### Frontend

- React (Vite)
- Tailwind CSS
- JavaScript (ES6+)

### Backend

- ASP.NET Core (.NET Minimal API)
- C#
- Cookie-based Authentication

### Database

- MongoDB Atlas (Cloud NoSQL Database)

## 🤖 AI API Used

- **Mistral AI API**
  - Used for generating AI responses
  - Supports streaming responses for real-time chat
